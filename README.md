**Projetos**

- **[Korvu Studio](https://github.com/korvuuk/korvu-studio)**: um estúdio de Reels sobre IA que roda no computador,
  do tema até a publicação no Instagram e no Facebook. Agentes do Claude Code pesquisam, escrevem o roteiro, editam o
  vídeo e publicam pela Meta Graph API; outros agentes auditam cada etapa antes de ela chegar a mim. As métricas de
  cada vídeo voltam para o próximo roteiro, e um painel web mostra a produção e o custo em tokens.
- **MUNTUZA**: plataforma de publicidade em telas verticais (digital signage). App do anunciante em Expo/React Native,
  player para Android TV e back-end no Supabase, com cartazes gerados por IA e moderação automática dos anúncios. O
  código é privado; o site está em [muntuza-site](https://github.com/korvuuk/muntuza-site).
